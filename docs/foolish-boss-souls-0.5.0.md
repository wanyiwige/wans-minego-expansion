# Foolish Boss 魂石实装记录（0.5.0）

新增 12 件饰品：十块 Boss 魂石、星渊之魂、Foolish之魂。配方及默认效果对应整合包的 `魔改与mod制作/Foolish_BOSS魂石设计_v2_参照MineFargo.md`。

## 配方、贴图与装备

十块单体采用 ` A /BOC/ D `，中央为空白魂石；上下左右原料逐项沿用 v2 表格。前九块无序合成星渊之魂，再与堕落之星魂石、Foolish 星辰催化剂合成最终魂石。两块合成品继承组成魂石能力，能力重叠时禁止装备，包括反向装备检查。

十张已确认的 Boss 源贴图保持不变，原有二十张学派贴图保持不变。两块合成品补绘为同样的 18×18 网格；外圈与中心符纹使用一致的原生像素大小。使用 Mine Fargo 的 `soul_stone` 饰品栏位，创造标签页只显示已注册物品。

## 效果实现

- 独立玩家冷却，不因卸下、重穿或在单块与组合品之间切换而重置。玩家退出会释放会话状态。
- 原始普攻、玩家投射物和 Iron 的 `SpellDamageSource` 可以触发效果；召唤物只获得女王伤害增益。环境火伤、持续状态伤害、魂石派生伤害不参与玩家攻击触发。
- 鞭打冲击、水花；雷鸟电弧、电火花；晶刺反击、附魔光迹；怨灵弹、灵魂火焰轨迹；星刃、末地烛轨迹与招架闪光均有服务器发送的视觉粒子。
- 怨灵弹和星刃使用真实的有归属追踪投射物，最长 3 秒，默认 24 格范围，遇实体目标命中、墙壁阻挡、目标或主人失效即清理。派生伤害绕过受伤无敌帧，保留护甲及其他防护，不重新触发本模组的 Boss 或学派派生能力。
- 紫晶晶震以短暂束缚实现普通敌人的失衡；Boss 只受轻微减速。怖蕈同样不束缚 Boss。控制遵守实体的 `canBeAffected` 判定；Boss 通过 `forge:bosses` 标签识别，补充十种 Foolish 实体。其他 Boss 的识别可通过数据包扩展该标签。
- 范围攻击选择周边敌对怪物、Boss、正在攻击玩家的生物和已被玩家攻击的敌对玩家，不自动波及中立村民和普通动物。队伍、自身宠物、同属召唤物及关闭友伤的玩家受到保护。
- 猩红随从为本模组的有主临时生物，采用红色分节虫模型；最多两只、18 HP、3 攻击、12 秒，无掉落、无经验。主人离线、换维度、死亡、卸下能力或超过 64 格时清理。不直接生成 Foolish 野生 Scarlant。
- 回血与派生伤害按 `min(目标剩余生命, 本次结算伤害)` 截断过量击杀部分。怖蕈共享每秒恢复预算。法力返还在施法扣款之后结算，跳过创造、无耗蓝来源和重施法，仅返还观察到的实际扣款（最多法术成本）；同 tick 的其他法力变化可能降低观测扣款。

## 动态依赖

基本前置仍为 Forge、Minecraft、Iron's Spellbooks、Curios、Mine Fargo。东方魔法由硬依赖改为可选依赖，移除了其直接 Java 类引用。

每块原有魂石按对应学派模组注册；多模组条件为：暗影需要 BielGG + Roaring，Relicron 需要 BielGG + EEEAB，无限需要 BielGG + Avaritia，污秽需要 BielGG + Wither Storm。其余映射见 `art/foolish-boss-stones-v1/dependency-matrix.json`。

Foolish 缺失时十二块新魂石及两个自定义生物不注册。条件在启动时生效，安装或移除模组需要重启。配方使用 Forge 1.20.1 的 `conditions` 数组，先检查模组再读取自定义条件；Curios 标签引用全部 `required:false`，避免不存在的物品令整张标签失效。

移除依赖后，已有存档中的对应物品会成为缺失注册内容，Minecraft 可能丢弃这些物品；这属于不注册该物品的结果。建议在移除前保留存档备份。

## 配置与验收

Boss 数值为服务端配置：单人存档 `saves/<世界>/serverconfig/wans_minego_expansion-boss-souls.toml`，专用服务器 `<世界>/serverconfig/`。可放入实例的 `defaultconfigs` 为新世界设默认值。概率、持续时间、冷却、派生伤害比例、回复上限、召唤属性等都可调；说明数值读取服务器同步配置。改变属性类数值后重新装备魂石。

源码改动前备份：`backups/20261006-150143-before-foolish-integration`。构建使用 Java 17 / Forge 47.4.18，发布包为 `build/libs/wans_minego_expansion-0.5.0.jar`。

静态检查覆盖全部 53 张配方、32 个可选标签引用、12 套物品资源、20 张原有贴图哈希、翻译参数及发布 JAR；纯 Java 边界检查覆盖过量击杀、吸血共享预算、低血量曲线、实际耗蓝与缺失依赖判断。构建检查与游戏运行验证分开记录。
