# 魂石设计准则

适用范围：Minecraft 魂石物品贴图的设计、重绘和审阅。当前 Wan's Minego Expansion 使用原生 18×18 网格；其他项目应先核实实际规格。

## 总原则

让主题参与整块魂石的造型、材质和构图；中央符号只是可选的一种表达方式。

先决定“这块魂石怎样构成”，再决定“中央放什么”。保持系列感，但不把所有魂石限制为统一轮廓、统一底盘和中央图章。

## 八条设计准则

| 准则 | 具体要求 |
| --- | --- |
| 1. 先确定主题特征 | 每张先提取 1—2 个最有辨识度的特征，例如魂衣的垂坠、磁极的两端、晶体的棱面、机械的装配结构。不能只确定颜色。 |
| 2. 按主题选择构图 | 可以采用材质型、结构型、镶嵌型、分区型、图景型或符号型。不同主题不必套用同一种底座。 |
| 3. 保留系列感，允许外形变化 | 保持相近的体量、像素密度和光照习惯；允许边缘出现晶簇、裂口、包覆、机械凸起等变化。统一风格不等于统一轮廓。 |
| 4. 内外使用同一像素网格 | 当前扩展模组以原生 18×18 绘制，中央与外侧一个像素的大小必须相同。禁止将高清图缩小后贴入中央；预览只用最近邻放大。 |
| 5. 颜色要有明确分工 | 区分主体材质、阴影、受光面与主题亮点。发光区域可以突破普通明暗，但不能把整块魂石都画成同样亮的色块。 |
| 6. 用结构建立差异 | 同系列可以共享纹样，但必须通过轮廓、材质、分区或内部结构形成区别。只换底色、只调亮暗，不算独立设计。 |
| 7. 优先保证小尺寸可读性 | 原尺寸下应能看清主要形态。每张突出一个视觉重点，避免同时塞入多个细小符号；细节不能依赖放大后才能成立。 |
| 8. 成品要放回整个系列审阅 | 同时检查原尺寸、统一倍数放大图和全系列总览。既要避免两张过于相似，也要避免某张画风、亮度或体量明显脱离系列。 |

## 六种构图方式

这些方式可以组合使用，不要求凑齐类型或平均分配数量。

| 方式 | 设计重点 | 合适的主题例子 |
| --- | --- | --- |
| 材质型 | 用整块表面的纹理、切面、透明感和边缘表现材质。 | 纸板、金属、云雾、琥珀、晶石。 |
| 结构型 | 用部件之间的连接、支撑、开口与方向组织本体。 | 磁极、格栅、轨道、机械、晶簇。 |
| 镶嵌型 | 核心被外壳、支架或包覆层承托，形成明确的内外关系。 | 封存灵魂、包裹晶核、魂衣包覆。 |
| 分区型 | 用左右、上下或交错区域表现属性关系。 | 双属性、对立磁极、复合材料。 |
| 图景型 | 以简化图景覆盖本体，利用层次、流向和区域建立主题。 | 云层、熔流、星空、地貌。 |
| 符号型 | 中央符号确实最适合表达主题时使用，不作为默认模板。 | 学派印记、印章、抽象概念。 |

## 从本体参考到扩展设计

2026-10-12 检查的 Mine Fargo 1.3.6 本体贴图提供了以下视觉参考：

- 纸板、浮云、炽铁魂石：整体材质与切面变化。
- 危险、步枪、疆域魂石：主题结构参与外形与边缘。
- 磁化魂石：左右分区与磁极结构。
- 四相、神躯、伊始之魂：多色拼接或整体渐变。

以上是对实际贴图的视觉分析，不是作者的设计说明，也不要求直接复制本体图案。

本次检查的本体单帧为 17×17，扩展模组为 18×18。借鉴构图时应在目标网格上重新设计，不能把不同规格的原图直接拉伸后视为原生像素画。动画长条 PNG 应按帧查看，不得将整条压缩成一张图标。

## 重绘范围

按用户指定的范围执行：

- 只改中央符号时，保留指定的外框、切面、配色和透明轮廓；不要自行扩大到整体造型重绘。
- 允许整体设计时，可以修改轮廓、材质、分区和镶嵌关系，不必保留固定的中央 8×8 底盘。
- 每组只改一张时，先明确重绘对象和保留对象；不要顺手修改另一张。

中央 8×8 是当前部分贴图的实现布局，不是所有魂石必须遵守的设计模板。内外同网格是硬要求，是否保留同一外框则由任务范围决定。

## 验收方法

### 视觉验收

1. 遮住名称后，能否看出主题的主要特征？
2. 去掉颜色差异后，与相近魂石是否仍有结构区别？对于以颜色关系为主题的设计，应同时检查其分区或材质关系。
3. 回到原生尺寸后，主要形态是否仍然清楚？
4. 中央与外侧像素尺度是否一致，有无局部细像素、模糊边缘或缩图痕迹？
5. 全系列并排时，是否存在仅换色的图案，或明显脱离系列的体量、亮度与画风？

### 文件与网格验收

- 确认目标分辨率、透明通道、动画帧规格和模型引用。
- 当前扩展模组的静态物品贴图为 18×18；保持既有透明处理，当前约定为 0/255 二值透明。
- 预览使用整数倍最近邻放大；每个原生像素在中央和边缘占据相同大小的方块。
- 局部重绘时，逐像素验证范围外区域不变；检查其他贴图未受到影响。
- 图案定义、正式 PNG 与重绘工具保持一致，避免下次重新生成时恢复旧图案。
- 相同图案占位或相同轮廓的比较用于筛选候选，不能替代视觉审阅。旋转、镜像、移位和相似材质也可能造成重复感。

## 交付要求

重绘前保留可恢复的源文件备份。交付正式贴图、原尺寸或统一倍数预览、前后及同组对照，并说明改动对象和验证结果。

源码贴图更新、构建成功、部署成功和游戏内视觉确认分别报告。设计或重绘请求不自动包含构建、部署或玩法改动。
